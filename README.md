## 先定用途：你要的是"IP 干净"，还是"机器能跑"

这两件事经常被混为一谈，但对应的产品完全不是一个方向。

第一种需求是 IP 属性。做 TikTok 运营、Facebook/WhatsApp 营销、亚马逊或 TEMU 店铺、跑 ChatGPT、解锁美区流媒体，这类业务对服务器的算力要求其实很低，1 核 1G 就够跑脚本，真正卡脖子的是 IP 段被标记成机房 IP、数据中心 IP，平台一看就知道不是真人用的网络。这类需求该看的是"住宅 IP""原生 IP"这两个词，而不是核心数。

第二种需求是机器性能。跑站点、跑数据库、跑自动化任务、装 Windows 挂软件，这类业务对 IP 属性不敏感，但 CPU、内存、硬盘、带宽必须撑得住。

丽萨主机主打的恰好是第一种：官方把美国纽约这条线写成"双 ISP 家宽住宅原生 IP"，把新加坡那条线写成"新加坡原生 IP"。它的定价逻辑不在算力性价比上，而在 IP 资源上。想清楚这一点，后面的选择会简单很多。

KVM 这个点值得单独说一句。它意味着你可以自己换内核、开 BBR、装 Windows、跑 Docker，虚拟化层面不受限。对需要折腾的人来说，这比多 1G 内存实用。

**第一，你需要国内直连快的话，这条线不合适。** 官方页面反复强调"非大陆直连优化网络，建议中转使用"，并且明确建议通过香港或日本线路中转、建议开启 BBR 加速。没有任何官方数据说明中国大陆直连的延迟和丢包情况，我也不打算编一个。如果你的业务场景是给国内用户建站、要求国内访问秒开，那你该找的是带 CN2 GIA、CMI 这类回国优化线路的产品，而不是这条国际大带宽的住宅 IP 线。

## 下单之后：从收到开通邮件到业务跑起来

买完之后大概率会卡在"不知道怎么用"。流程其实不长，五步：

**第一步，下单。** 选好套餐，付款。页面写的是自动开通、即时交付，不用等人工审核。

**第二步，收开通邮件。** 邮件里会有服务器 IP、root 密码，以及管理面板地址。第一时间把密码改掉，能加 SSH 密钥就加上，裸密码暴露在公网上很容易被扫。

**第三步，SSH 登录。** Mac 直接用终端，Windows 用 PuTTY 或 Xshell，执行 `ssh root@你的IP`，输入密码进去。官方建议开启 BBR 加速，这一步在登录后就可以做，对国际线路的吞吐帮助比较明显。

**第四步，装环境。** 如果是要跑站点，新手最省事的是装宝塔面板，一行命令把 LNMP 环境配好，剩下都在浏览器里点。如果只是跑脚本，那装个 Python、Node 或者 Docker 就够了，不用上控制面板——1G 内存的机器上面板本身就要吃掉一部分。

**第五步，部署业务并配好解析。** 建站的把域名 DNS 指向服务器 IP，跑脚本的把任务挂上去。如果打算用中转，这一步之前就要把中转链路调通，否则你会误以为是机器的问题。

整套流程第一次走大概一两个小时，熟悉之后半小时内能完成。真正花时间的不是装环境，是调通中转和验证 IP 在你目标平台上的表现。
